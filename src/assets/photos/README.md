# Website photos (drop-in)

Save a picture in this folder with one of the file names below and it shows
up on the site by itself, no code change needed. Any of .webp, .jpg, .png
works. Until a file is here, that spot shows a real screen from the demos.

Tips
- Keep the size listed, and each file under about 400 KB (export as WebP or
  JPG at 80% quality, e.g. with squoosh.app).
- No text, logos or watermarks inside the picture: the site writes the words.
- Leave the left third calm and darker on banners: the heading sits there.
- Only use pictures you have the right to use (your own AI images or photos,
  or licensed stock).
- AI prompt style that matches the reference: "photorealistic, corporate
  photography, Indian professionals, natural light, shallow depth of field,
  blue and warm orange tones, no text, no logos".
